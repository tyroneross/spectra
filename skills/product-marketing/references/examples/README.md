# Product marketing examples

This catalog preserves source-linked product-marketing videos and explains why
their structure works. Each example separates observable production choices from
interpretation so the pattern can be reused without copying the campaign.

| Example | Format | Reusable pattern | Source |
|---|---|---|---|
| [HeyClicky: screen-aware dictation](heyclicky-screen-aware-dictation/README.md) | Founder-led feature launch, 2:00, 16:9 | Familiar baseline -> honest contrast -> differentiated reveal -> contextual proof -> breadth -> candid close | [Farza on X](https://x.com/farzatv/status/2077130366230639022) |

## Example package

Each example directory should contain:

- `README.md` — timestamped story, person/product choreography, craft analysis,
  and reusable lessons.
- `video.mp4` — review copy when archiving is appropriate and practical.
- `poster.jpg` — source thumbnail or representative frame.
- `storyboard.jpg` — chronological visual overview.
- `metadata.json` — source attribution, media checksums, measured properties,
  and analysis method.

Source creators retain all rights. The copies in this catalog are preserved as
attributed references for internal product-marketing study.
